# Biblioteca — A soma da Palavra

Traduções em **português** e **espanhol** de obras cristãs clássicas em **domínio público**, feitas para o site [A soma da Palavra](https://somadapalavra.com.br), um estudo bíblico gratuito com referências cruzadas.

Cada obra traz o texto original em inglês e as traduções, capítulo por capítulo, em Markdown, além do livro completo em PDF e EPUB.
